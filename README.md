## 🚀 Проекты

### 1. Автотесты для страницы авторизации (UI)
*   **Задача:** автоматизировать проверку формы авторизации и валидации полей.
*   **Реализация:** реализовала Page Object, написала 15 тестов, настроила запуск через Maven.
*   **Стек:** Java, Selenide, Maven, TestNG, SLF4J Simple, Selenium DevTools.
*   **Результат:** тесты стабильно запускаются локально, отчет формируется в консоли, сокращено время прогона.

### 2. Автотесты для сервиса Диск (REST API)
*   **Задача:** проверка работы методов GET, POST, PUT, DELETE.
*   **Реализация:** реализовала Page Object, написала 44 теста.
*   **Стек:** Java, Maven, JUnit, REST Assured, Hamcrest.
*   **Результат:** тесты стабильно запускаются локально, сокращено время прогона относительно ручного тестирования в разы.

### 3. Автотесты для веб-сервиса (REST API)
*   **Задача:** проверка работы метода POST, валидации данных, авторизации, взаимодействия с внешним сервисом и обработки ошибок.
*   **Реализация:** для обращения к внешнему сервису использовались моки, написала 27 тестов.
*   **Стек:** Java, Maven, JUnit, REST Assured, Hamcrest, WireMock, Allure, SLF4J Simple.
*   **Результат:** тесты стабильно запускаются локально, формируется отчёт.

### 4. Тестовая документация для веб-страницы
*   **Задача:** разработать чек-лист, тест-кейсы и завести баг-репорты главной страницы веб-сайта.
*   **Результат:** создан чек-лист на 77 проверок и 2 тест-кейса, после проверки найдены и заведены 2 бага.

### 5. Баг-репорты по функционалу веб-сайта
*   **Задача:** проверить веб-сайт на соответствие требованиям ТЗ с использованием обращений к БД и API документации.
*   **Стек:** Postman, PostgreSQL.
*   **Результат:** найдены и заведены 11 багов на фронтенде, бэкенде и базе данных.

### 6. Тест-кейсы для веб-приложения на мобильном устройстве
